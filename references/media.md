# 기술 시각 자료

기존 _assets를 먼저 찾고 자료가 설명할 질문을 정한다. 연결 경로, 실제 커넥터 식별, 측정 비교는 다른 시각 자료가 필요하다. 장식은 추가하지 않는다.

자체 개념도·Mermaid, 재사용 조건이 명확한 자료, 공식 페이지 링크를 활용한다. 공식 이미지도 재배포가 자동 허용되지는 않는다. 권리·원본·제품·리비전·캡션·alt·경로를 확인한다.

생성 이미지를 실물 사진처럼 제시하지 않는다. 핀 수·키 홈·CPU 소켓·PCIe 접점·헤더를 상상으로 그려 규격도처럼 쓰지 않는다. 개념도와 실제 배선을 구분한다. 측정 그래프는 실제 조건·원자료를 바탕으로 만든다.

브라우저·이미지 생성기는 스킬에 내장돼 있지 않다. 현재 실행 도구의 기능과 권한 안에서 작업한다. hmy-media 경로 허용과 파일 존재·권리 확인은 별도다. 기존 이미지·각주·캡션이 편집 뒤에도 올바른 대상을 설명하는지 확인한다.

이미지 비교는 지원되는 hmy-media.compare를 사용하고 양쪽 source/license/alt와 비교 조건을 각각 확인한다. 같은 종횡비·정상 로드가 아니면 슬라이더 없이 원본 비교가 남을 수 있다. 확대·range를 썼다고 물리 규격이나 실측이 검증된 것은 아니다. 구조·데이터·신호를 고를 때는 [설명 형식](visual-explanations.md), 수치는 [데이터 시각화](data-visualization.md)를 읽는다.
