# 규격과 호환성

폼팩터·커넥터·키, 전기적 연결, 전송 계층, 명령 프로토콜, 펌웨어·OS 지원을 나눈다. M.2와 NVMe, USB-C와 전송속도, 슬롯 길이와 전기적 PCIe 레인 수는 같은 정보가 아니다.

PCIe는 세대·연결 폭·CPU 직결·칩셋 업링크·공유·bifurcation·실제 배선을 함께 본다. 한 플랫폼의 레인 수나 DMI 세대를 모든 PC에 적용하지 않는다. 동시 부하의 공유 제한과 항상 느리다는 단정은 다르다.

DDR5-5600은 5600 MT/s, 대응 클럭은 약 2800 MHz다. CAS latency는 주기 수와 클럭을 결합해야 시간으로 바뀌며 전체 접근 지연과 다르다. Memory Training은 시작 시점 신호 조정으로, 장기 안정성 시험을 대신하지 않는다.

최대 규격과 제품 구현, 이론과 실측을 구분한다. 계산에는 단방향/양방향, bit/byte, encoding overhead, lane 수를 명시한다. 실측에는 결론에 영향을 주는 CPU·보드·펌웨어·메모리·OS·드라이버·도구·부하·반복·온도 조건이 필요하다.

CPU Support List와 QVL은 대상 CPU·키트·DIMM 구성·BIOS를 확인한다. 미등재를 불량이나 무조건 미지원으로 단정하지 않는다. 동일 상품명도 리비전·구성을 구분한다.
