# 기존 지식을 확장하기

신규 작성 전에 파일명 → title → aliases → 본문·섹션 → 허브·백링크를 찾는다. 검색 범위와 용어를 기록해 중복 조사를 줄인다. 같은 대상·범위의 다른 이름이면 기존 canonical 문서나 섹션을 보완한다. 메모리 타이밍과 Memory Training은 관련되지만 목적이 다르다.

정의만 있는 문서에는 동작·실제 영향을, 설명은 충분하나 흐름이 어려운 문서에는 구조를 보완한다. 목적을 다한 짧은 문서는 그대로 둔다. 길이로 일괄 등급을 매기지 않는다.

허브는 분야 구조를 먼저 설명하고 개념을 배우는 경로와 증상에서 진단으로 가는 경로를 구분한다. 회사 역사를 여러 허브에 복사하지 않는다. 새 문서나 주요 확장 뒤에는 관련 허브를 확인한다.

링크 수보다 의미 있는 관계를 우선한다. 현재 문서의 핵심 설명·안전 조건은 본문에 남긴다. 병합·이동·경로 변경은 유입 링크 영향을 조사하고 요청 범위 안에서 수행한다.

전체 작업은 대상 목록을 고정하고 각 문서의 유지·수정·보류 이유와 검사 상태를 관리한다. 목록과 coverage는 내부 기록에만 둔다.
