# 주장과 근거

규격은 표준화 단체, 지원 조건은 정확한 모델의 매뉴얼·데이터시트·CPU Support List·QVL, 기업 관계는 공시·공식 발표를 우선한다. 자료의 유명세보다 해당 주장을 뒷받침하는지가 중요하다.

내부 조사 기록에 주장, URL, 원문 날짜·버전, 읽은 부분, 적용 모델·범위, 확인일, 상반 자료·접근 실패를 남긴다. 검색 요약이나 HTTP 200은 원문 확인이 아니다. 읽지 못한 문서의 내용·URL·수치를 추측하지 않는다.

별도로 대조할 항목은 숫자와 단위, 세대·출시일, 모델·리비전, 이론 대역폭과 실제 처리량, 최대 지원과 기본 동작이다. 관찰과 가설, 규격의 가능성과 제품 구현, 공식 결함 공지와 커뮤니티 사례, 회사 주장과 독립 측정을 구분한다.

계산은 입력·단위·가정을 보인다. 다른 조건의 벤치마크를 같은 순위표로 합치지 않는다. 측정하지 않은 값을 결과 블록에도 쓰지 않는다.

지원·펌웨어·규격 버전·유통 관계는 작업 시점에 재확인한다. 역사적 사실을 현재 시점으로 덮지 않는다. 근거가 부족하면 필요한 기술적 한계를 설명하거나 새 주장을 제외하고 조사 공백은 보고에 남긴다.

공개 외부 자료 절은 “참고 링크”다. 중요한 주장 옆에도 근거를 연결할 수 있다. 자료가 충돌하면 날짜·모델·리비전부터 비교한다.

차트와 입력 탐색기는 데이터 출처·조건·단위와 계산의 적용 범위를 본문에 남긴다. CAS 계산을 전체 요청 시간으로, PCIe 부호화 계산을 파일 복사 실측으로 확대하지 않는다. 값 변경 시 표·본문·plot·baseline·캡션을 함께 확인한다. [수치 시각화](data-visualization.md)의 차원·방향·부호화 대조를 적용한다.
