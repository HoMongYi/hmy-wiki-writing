# 새 기술문서: PCIe 레인과 데이터 경로

이 예시는 패키지 집필자가 공식 자료를 확인해 구성한 독립 예시다. 실제 모델의 무편집 출력과는 다르며 HMY 운영 문서를 변경하지 않았다.

요청: PCIe 레인과 슬롯의 관계를 설명하고 CPU 직결·칩셋 경유가 SSD와 확장카드 구성에 미치는 영향을 연결한다.

[전체 결과](fixtures/vault/01_하드웨어/PCI%20Express.md)는 슬롯 길이와 전기적 폭, 업링크 공유, 동시 부하 조건을 구분한다. [자체 개념도](fixtures/vault/_assets/data-path.svg)는 제품별 배선을 주장하지 않는다. 실제 보드의 레인 수나 성능 측정값은 만들지 않았다.

[메모리 타이밍](fixtures/vault/01_하드웨어/메모리%20타이밍.md)과 [Memory Training](fixtures/vault/01_하드웨어/Memory%20Training.md)은 서로 다른 개념을 기존 별칭으로 찾고 연결하는 추가 사례다. 전송률·클럭·계산값과 시스템 전체 지연을 구분한다.
