# NVMe 고도화 전후

공식 자료를 확인해 집필자가 구성한 독립 편집 예시다. [원문](fixtures/before/NVMe.md)과 [전체 결과](fixtures/vault/01_하드웨어/NVMe.md)를 나란히 읽을 수 있다.

원문은 NVMe의 정의와 M.2·PCIe의 구분만 설명한다. 결과는 호스트와 컨트롤러, 제출·완료 큐, 명령 식별, PCIe 전송 경로, M.2 호환 조건을 연결한다. 기존 Frontmatter와 두 Wikilink, 공식 규격 링크, 정확한 두 문단을 유지했다.

큐 설명은 직접 열람한 NVM Express 1.0e의 기본 동작과 Microsoft 완료 항목 문서에 근거한다. 추가 확인하려던 Base 2.1 PDF는 HTTP 403으로 열지 못했다. 2.1은 최신판이 아니다. 2026-10-22에 읽은 공식 소개는 2026-08-04 공개된 2.4 규격군을 안내한다. 최신 규격군의 소개와 개별 PDF 세부 내용의 검증은 구분하며, 이 예시의 큐 설명을 최신판 전체 검증으로 확대하지 않는다.

블록은 넣지 않았다. 이 문서의 핵심 공백은 항목표가 아니라 동작의 연결이기 때문이다. 보존 검사는 scripts/validate.py, 실제 문법·대상 검사는 scripts/verify-hmy.mts가 담당하며 기술 의미는 별도 검토한다.
