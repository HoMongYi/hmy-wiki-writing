# NVMe

NVMe는 호스트 소프트웨어가 비휘발성 저장장치와 통신하는 방식을 정의한다. PC의 PCIe SSD에서는 운영체제의 드라이버와 SSD 컨트롤러가 명령과 완료 정보를 교환한다.

M.2는 모듈의 형태와 연결 규격을 다루며 NVMe와 같은 뜻이 아니다. [[PCI Express]]와 [[M.2]]는 서로 다른 층위의 규격이다.
