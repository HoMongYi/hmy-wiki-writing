# 독립 fixture Vault

이 폴더는 스킬 집필과 검증을 위해 새로 만든 예시다. HMY 운영 콘텐츠의 사본이나 실제 하드웨어 측정 보고서가 아니다. vault/를 Obsidian에서 열거나 격리된 Quartz 입력으로 사용할 수 있다. before/는 같은 논리 경로의 편집 전 원문이다.

본문의 공식 자료는 evals/sources.json에 확인 범위를 기록한다. data-path.svg와 cpu-direct.svg·chipset-shared.svg는 자체 제작 개념도이며 MIT로 배포한다. 실제 제품 사진·로고는 포함하지 않는다. 운영 프로젝트에 적용할 때에는 문서 중복·링크·공개 상태를 다시 확인한다.

[생태계 예시](../industry-ecosystem.md)는 설계·위탁 생산 역할을 다룬다. [문장 교정](../light-edit.md), [고도화](../deep-improvement.md), [개념](../concept-writing.md), [진단](../troubleshooting.md), [기업](../company-profile.md), [역사](../history-timeline.md), [허브](../wikilinks-hub.md), [블록](../hmy-blocks.md) 설명을 함께 제공한다.

[시각적 설명 예시](../visual-documentation.md)는 관계·계층·숫자·입력·분기를 구분한다. 추가 근거는 [시각화 자료](../../evals/visual-sources.json), 실제 지원·검증은 [시각화 결과](../../evals/visual-results.md)에 기록한다.
