# Memory Training

Memory Training은 부팅 과정에서 메모리 동작을 위한 신호 조건을 맞추는 초기화 과정이다. 메모리 교체나 설정 초기화 뒤 첫 부팅에서 화면이 늦게 나타나는 현상과 관련될 수 있다. 화면이 없다는 관찰만으로 Training 중인지 다른 문제인지 확정할 수는 없다.

ASUS의 안내는 메모리 교체 등의 조건에서 다음 부팅에 전체 Training이 필요할 수 있다고 설명한다. 소요 시간과 표시 방식은 모델과 메모리 구성에 따라 다르므로 특정 안내의 대기 시간을 모든 PC의 한계로 적용하지 않는다. 해당 모델 안내에 따라 기다리는 동안 반복 강제 종료는 피한다.

Training 후 부팅에 성공했다는 결과와 장시간 부하의 안정성은 다른 관찰이다. 부팅이 되는지, 냉간 부팅과 재부팅에 차이가 있는지, 실제 작업에서 오류가 재현되는지를 구분해 기록한다. Training이 실패해도 모듈 하나만의 불량으로 확정하지 않는다.

동작 중 명령 간 지연은 [[메모리 타이밍#CAS Latency]]에서 설명한다. 별칭인 “메모리 트레이닝”을 새 문서로 만들기보다 이 문서로 연결할 수 있다.
