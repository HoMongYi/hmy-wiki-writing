# 여러 문단의 Light Edit

집필자가 구성한 독립 예시다. [원문 전체](fixtures/before/M.2%20점검.md)와 [결과 전체](fixtures/vault/01_하드웨어/M.2%20점검.md)를 제공한다. 경로·자산의 기준은 결과 fixture Vault이며 before 파일도 같은 논리 문서의 원문으로 비교한다.

전: 연결 방식의 확인을 위해서는 메인보드 매뉴얼에서 해당 슬롯의 사양을 조회하는 것이 필요하다.

후: 연결 방식을 확인하려면 메인보드 매뉴얼에서 해당 슬롯의 사양을 살펴본다.

이 문장 한 개만 고쳤다. 이미 자연스러운 첫 문단, 전원·데이터 보호 조건, 공유 자원 설명, 중첩 custom_field, sources, 링크와 섹션 앵커, 이미지·alt, 각주 정의는 그대로다. 검사기는 전체 텍스트가 이 한 번의 치환과 일치하는지 확인한다.
