# Knowledge Linking

[지식 구조](../references/knowledge-architecture.md)와 [링크 해석](../references/wikilinks-backlinks.md)을 읽는다.

파일명·title·aliases·섹션으로 개념을 찾고 같은 대상/다른 범위를 구분한다. 링크를 추가하기 전에 두 문서의 실제 설명을 읽는다. 현재 문서의 핵심 문장을 유지한 채 독자가 다음에 필요한 설명을 연결한다.

허브에서는 학습 흐름과 문제 해결 경로를 짧은 설명으로 연결한다. 새 링크의 목적지·섹션·공개 상태를 확인하고 현재 문서를 가리키는 유입 링크도 살핀다. 별칭 탐색 성공, canonical 링크, 별칭 리디렉션을 구별한다.

허브나 링크를 요청받았다고 병합·이동·경로 변경을 자동 수행하지 않는다. 결과 보고는 추가·수정한 관계와 미해결 대상, 실제 렌더 확인 범위를 포함한다.
