# Topic Deepening

정의만 있는 기술문서를 Deep Improvement할 때 사용한다. [유형](../references/document-types.md)과 [근거](../references/technical-accuracy.md)를 선택해 읽는다.

대상 전체를 읽고 보존할 사실·참조·메타데이터를 기록한다. 기존 관련 문서에서 이미 설명하는 범위를 찾는다. 독자의 질문을 “무엇인가, 어떻게 작동하는가, 왜 이런 현상이 생기는가, PC 구성에서 어떤 조건이 달라지는가”로 구체화한다.

공백에 필요한 공식 근거를 조사하고 설명 순서를 구성한다. 핵심 동작을 이 문서에 남기고 다른 문서의 본론은 짧은 연결 문장과 Wikilink로 잇는다. 기술 관계가 잘 보이는 표나 도식만 선택한다. 블록을 쓰지 않는 결과도 정상이다.

원문과 비교해 사실·예외·안전 조건이 사라지지 않았는지 확인한다. 허브와 backlink, 렌더를 점검하고 새로 확인한 근거와 미확인 사항을 별도 보고한다. 분량 증가를 개선 근거로 쓰지 않는다.
