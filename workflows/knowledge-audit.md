# Knowledge Audit

Review Only로 전체 또는 지정 분야를 조사할 때 사용한다. [검토 항목](../references/review-checklist.md)을 읽는다.

1. 실제 공개 정책과 사용자 범위의 교집합을 문서 목록으로 고정한다. 전체 목록과 실제 읽은 목록을 구별한다.
2. 파일명·title·aliases·본문·링크·자산을 검색한다. 정보 부족, AI 문체, 반복, 모순, 중복 개념, 깨진 링크, 불필요한 블록, 메타데이터, 최신성을 조사한다.
3. 자동 탐지 결과를 실제 문맥에서 확인한다. 짧은 문서·적은 링크·특정 단어 자체를 결함으로 분류하지 않는다.
4. 문서별로 위치, 문제, 독자 영향, 근거, 권장 모드와 우선순위를 내부 보고에 남긴다. 우선순위는 안전·사실 오류→끊긴 탐색→설명 공백→문체 순으로 조정한다.
5. 조사한 수·전체 수·미조사 목록·접근 실패를 보고한다. 표본 검사이면 표본이라고 밝힌다. 원본·공개 상태는 수정하지 않는다.

결과는 “어느 문서를 왜 어떻게 개선할지” 판단할 수 있는 목록이다. 전체 개선 요청으로 이어지면 [Repository-wide Improvement](repository-improvement.md)를 사용한다.
