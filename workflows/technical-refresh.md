# Technical Refresh

Refresh 모드로 버전·지원·규격·기업 관계를 최신화한다. [사실 확인](../references/technical-accuracy.md)을 읽는다.

변할 수 있는 주장을 원문에서 추출하고 모델·지역·리비전·시점을 붙인다. 현재 공식 자료의 실제 해당 부분을 읽고 기존 근거와 비교한다. 발표와 적용·완료 날짜를 나눈다.

바뀐 주장과 직접 영향을 받는 설명·링크만 갱신한다. 과거 이력은 당시 사실로 유지한다. 지원 종료나 UI 변경을 확인하지 못했다면 새 값을 추정하지 않는다. 알 수 없는 Frontmatter를 삭제하거나 verified·human_reviewed를 자동 승격하지 않는다.

보고에는 변경 전후·근거·확인일·접근 실패를 남긴다. 최신 페이지를 열었다는 사실만으로 문서 전체를 최신화했다고 쓰지 않는다.
